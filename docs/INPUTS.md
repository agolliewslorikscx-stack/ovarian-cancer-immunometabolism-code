# Input contracts

All paths below are relative to the input project directory passed to `run_analysis.R`. No input datasets are distributed in this release. Run `--check-only` to inspect required files before analysis. This checks existence, not scientific provenance or full schema validity.

## Public sources

- GWAS: IEU OpenGWAS, https://opengwas.io/ . The MR wrapper requires explicit exposure and outcome IDs. The example `met-d-DHA` / `ieu-a-1120` is a configuration example, not a result.
- TCGA: Genomic Data Commons, https://portal.gdc.cancer.gov/ . The scripts consume a separately prepared gene-symbol log2-TPM matrix and WGCNA intermediate results; they do not download or preprocess TCGA.
- Single-cell reference: GEO GSE184880, https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE184880 . The composition script requires a separately annotated cell metadata table; raw GEO downloads alone do not provide this project's final annotations.
- Gene sets: MSigDB GMT distributions, https://www.gsea-msigdb.org/gsea/msigdb/ . Obtain the exact files under their applicable access and use terms.

## Module association

1. `data/TCGA_OV/processed/TCGA_OV_log2TPM_primary_tumor_for_score.tsv`: first column gene symbols, remaining columns numeric expression indexed by sample barcode.
2. `results/15_TCGA_WGCNA/WGCNA_module_eigengenes.csv`: `sample_barcode` and module eigengene columns. The script expects 13 non-grey modules and exactly 426 matched samples.
3. `results/15_TCGA_WGCNA/WGCNA_module_assignment.csv`: `gene_symbol` and `module` (e.g. `blue`, `brown`); a `module_eigengene` column may also be present.
4. `outputs/Figure2A_6stage_myeloid_programmes_20260916/02_programme_definitions_frozen.csv`: `programme`, `exact_gene_list` (semicolon-separated symbols), `freeze_status` containing `FROZEN` or `PASS` for the six specified programmes. Supply the actual definitions from the analysis; do not invent gene lists to pass the checks.

The six required programme names are `Myelopoietic Signalling`, `Inflammatory Priming`, `Chemokine Recruitment`, `Endothelial Transmigration`, `Myeloid State Differentiation`, and `Tumour Myeloid Remodelling`.

Outputs are written under `outputs/Figure2C_WGCNA_6programme_20260916/`.

## Core genes

Requires all four files above plus `outputs/Figure2C_WGCNA_6programme_20260916/01_TCGA_6programme_scores_426x6.csv`, generated by the module association script. The assignment table must contain `gene_symbol` and `module`; eigengenes and scores must contain `sample_barcode`. Outputs go under `outputs/Figure2E_core_gene_prioritization_20260917/`.

## Enrichment

Requires the WGCNA assignment table above and these separately downloaded files:

- `data/gene_sets/h.all.v2025.1.Hs.symbols.gmt`
- `data/gene_sets/c2.cp.reactome.v2025.1.Hs.symbols.gmt`
- `data/gene_sets/c5.go.bp.v2025.1.Hs.symbols.gmt`

The universe consists of all genes in the assignment table. Outputs go under `outputs/Figure3A_MEblue_MEbrown_enrichment_20260917/`.

## Donor composition

Requires `outputs/FIG4A_SINGLE_CELL_ECOSYSTEM_ATLAS_PUBLICATION_REDRAW_V1/02_PLOT_DATA/FIG4A_umap_plot_ready.csv` with `cell_id`, `patient_id`, `disease_group`, `major_compartment_primary`, `display_label`.

Disease labels are `HGSOC` and `NON_HGSOC_NORMAL` (or `Normal`). Each donor must map to one disease group. Broad identities are Malignant, Normal epithelial, Myeloid, T/NK, B/plasma, Stromal, Endothelial and unresolved. The script retains the source mapping of Fibroblast/stromal and Other_unresolved. Outputs go under `outputs/Figure4_cell_composition_violin_20260917/`.

## MR

The wrapper constructs a temporary worker configuration with explicit exposure/outcome IDs. The worker queries OpenGWAS or reuses cached instruments under `results/mr/00_exposure_audit/`. Outputs go under `results/mr/`; no credentials are written by the wrapper. Set `OPENGWAS_JWT` only in your private environment. Do not place environment files in the repository.
